# Student Management System
A desktop-based **Student Management System** developed using **Java Swing**. This application provides a simple graphical interface for managing student records. Users can add, update, delete, and view student information through an interactive table.

## Features
- Add new student records
- Update existing student details
- Delete student records
- Clear input fields
- Display student data in a JTable
- User-friendly graphical interface built with Java Swing

## Technologies Used
- Java
- Java Swing
- AWT
- JTable
- DefaultTableModel

## Application Functions

- Add Student
- Update Student
- Delete Student
- Clear Form
- Exit Application
